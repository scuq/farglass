## Goal
Linux GUI apps and Chromium in farglass windows, fast on a host with no GPU, with no video codec.

## Exit criteria
Chromium on the host shows in a farglass window. Text is exact. An idle window uses no CPU. To scroll a text page sends move commands and new strips only. The pointer moves with no network delay.
